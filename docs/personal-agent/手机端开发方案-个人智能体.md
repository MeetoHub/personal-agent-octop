## 3. 页面一：对话（主入口）

### 3.1 保留
- 现有 `ChatScreen.kt` v7 全部视觉（8.5 分基线）
- 空状态欢迎卡（6 张 quick card）
- 头像、标题、气泡、输入框

### 3.2 改动

| # | 改动 | 原因 |
|---|---|---|
| 1 | **接入 thread 历史** | 当前只有一条 thread，无历史/切换/新建。后端 `POST /api/agents/{id}/threads` + `GET .../threads` 已有 |
| 2 | 顶栏高度 60→52dp，「已连上本体」移到名字右侧 | 信息密度（原扣 0.5） |
| 3 | 输入框 placeholder 改为个人场景文案 | 现在还是 `让 Octop 做点什么…` |
| 4 | 长任务出现"我先办，办完回来汇报"回执卡 | 三分态：acknowledgement / reply / notice |
| 5 | 消息气泡内联 ticket 状态条 | 一句话就能看到"这活在跑" |

### 3.3 三分态 UI（关键，决定效果感知）

DSH `src/core/ports.ts` 的设计：
```ts
kind: 'acknowledgement' | 'reply' | 'notice'
```

| 类型 | UI 表现 | 时机 |
|---|---|---|
| acknowledgement | 小字灰色"已收到，我来办" | 立即 |
| reply | 正常专家气泡 + 结果 | 完成 |
| notice | 琥珀色提示卡 + 操作按钮 | 需人工 |

**必须视觉区分，否则用户分不清"答应了"和"做完了"。**

## 5. 页面三：团队（专家 + 人格两段）

### 5.1 结构（对应"专家有记忆、子智能体没有"）

```
团队
├─ 我的专家（有记忆）
│  ┌────────────────────────────────┐
│  │ 🏠 生活管家      主专家         │
│  │    记忆 128 条 · 在线           │
│  ├────────────────────────────────┤
│  │ 💰 财务助手      记忆 47 条     │
│  │ 💻 工程助手      记忆 12 条     │
│  └────────────────────────────────┘
│  ＋ 新建专家
│
└─ 人格（无记忆，主专家内部切换）
   ┌────────────────────────────────┐
   │ 🧬 数据修复      [已启用]       │
   │ 📊 财务分析      [已启用]       │
   │ ✍️ 文案写作      [未启用]       │
   └────────────────────────────────┘
   ＋ 添加人格（16 个部门）
```

### 5.2 关键设计
- **专家卡必须显示记忆条数**——这是用户能感知"有记忆"的唯一入口
- 人格卡不显示记忆，只显示启用开关
- 两段标题要明确写"有记忆 / 无记忆"

### 5.3 数据来源（全部现成）
```
GET /api/agents                    → 专家列表（含 memory 字段）
GET /api/agents/{id}/subagents     → 已装子智能体
GET /api/subagent-catalog/divisions → 16 部门
GET /api/subagent-catalog          → 角色列表
```
**无需新后端。**

## 8. 本地工具与权限（分三批）

### 8.1 权限阶梯

| 批次 | 能力 | 权限 | 风险 |
|---|---|---|---|
| 一 | 日历/联系人/通知只读 | 标准 `requestPermissions` | 低 |
| 二 | 打开 App / 点按 | Shizuku 或无障碍 | 中 |
| 三 | 组合任务 | 前两批之上 | 高 |

### 8.2 「我的 → 手机权限」页

```
📱 手机权限

📅 日历        允许读取你的日程      [开启]
👥 联系人      允许查找联系人        [开启]
🔔 通知        允许读取最近通知      [关闭]
📱 控制手机    需要 Shizuku         [未安装]
               ⚠ 开启后可代替你操作 App

🚨 全局停止    任何时候可立即中止    [常驻]
```

### 8.3 安全（硬要求）
- 每项独立开关
- 不可逆操作强制二次确认
- 熔断：连续 N 步无进展自动停
- 敏感数据不出设备（只回传结果）
